## What it carries that 1.1.2 does not

**Semantic search** — finds tours by meaning, on-device, with a one-off 42 MB model download on
first use; spelling correction against the catalogue's own vocabulary; and each result quotes the
sentence that matched. **More like this** on a tour page. **More like what you saved** on the home
screen, second, reading **both** Liked and named lists. **Delta catalogue sync** — the app asks for
only the rows that moved instead of re-downloading 2.4 MB. **Cache self-heal**, a `Clear Cache` that
actually clears the catalogue, and an **Updated** row in Settings → About. **Four date-sort controls
that have rendered and done nothing since June.**

## ⚠️ How the scope was derived, because the obvious method was wrong

`git log <released>..HEAD -- '*.swift'` listed **six** commits. The **file diff over the same range**
contains `SemanticSearch.swift`, `QueryEmbedder.swift`, `WordPieceTokenizer.swift`,
`CatalogDeltaMerge.swift`, `vocab.txt` and 30k lines besides — features from PRs the log never
showed. **This checkout is a SHALLOW clone**, so `git log` path-filtering and
`merge-base --is-ancestor` both give incomplete answers here (`--is-ancestor` returned false for six
commits that are demonstrably in the tree).

🔴 **A commit list is not a scope. The file diff is.** Had the notes been written from the log, this
release would have been described as a cache fix and a button rename, and **the four largest
features in it would have gone unmentioned to Apple and to the owner.** Every user-visible string in
the notes was then grepped out of `main` before being promised.

## Riskiest thing in it

**The catalogue-sync rewrite.** It changes how every phone gets its content, it is the one change
nobody in the field has ever run, and its failure mode is quiet — wrong or missing content rather
than a crash. The notes ask for a general "do tours, photos and the map still look right" pass for
exactly that reason.

**Also flagged for device check:** the *More like what you saved* row **via a named list, not just
Liked** — that is the precise case that was broken on build 169 and fixed in 170.
