**The floor, 0.45 → 0.35** (#963). 166's silenced queries now work.

🔴 **The root cause is a category error worth keeping.** `scoreFloor` had been **copied from
`RELATED_FLOOR`**, the number "More like this" uses — but those gate different comparisons.
`RELATED_FLOOR` compares two TOURS, mean-to-mean, two long documents that score high against each
other by construction. This compares a **short typed query** against a long document, which scores
far lower for the same quality of match. **Reusing the constant looked like consistency.**

**0.35 was measured in both directions, not chosen by taste:** nonsense still returns nothing
(`asdfgh qwerty zxcvb` tops 0.3361, *"my tax return"* 0.2392, *"how do i reset my password"*
0.1376), while *"somewhere romantic for a date"* starts working.

⚠️ **The number that proves it was in the verification output all along** — `verify-coreml-parity.py`
had been printing top score 0.4136 for *"quiet garden away from crowds"* on every ranking run. It was
read as a ranking check rather than as a distribution. **A floor wrong by a hair does not degrade,
it disappears.**
