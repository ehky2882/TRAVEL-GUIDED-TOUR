# Version bumped to 1.1.3 after 1.1.2 released

_2026-09-15 01:00 UTC · branch `bump-1-1-3`_

**Version bumped 1.1.2 → 1.1.3** on owner request, the day 1.1.2 was released.

`MARKETING_VERSION` changed on the two app-target configurations (Debug + Release) in
`project.pbxproj`. The four `1.0` entries are the test targets and are untouched.
`Info.plist` reads `$(MARKETING_VERSION)`, so nothing else carries the number.

Why: 1.1.2 is released, so Apple has closed its train. Any TestFlight upload still
numbered 1.1.2 would be refused with 90186 `Invalid Pre-Release Train`. The next
build from `main` will be `1.1.3 (N)`.

No behaviour change. Code-class file (`*.pbxproj`), so merge waits for green CI;
there is nothing to review visually.
