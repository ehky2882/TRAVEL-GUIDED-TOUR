## The three lessons worth carrying

1. **Guard push refspecs.** An empty `$COMMIT` deleted the gh-pages branch and took the CDN
   down for 13 minutes. Recovery is `gh api -X POST .../git/refs`, never `git push` from a
   blobless clone. Prefer the Contents API for single-file edits.
2. **A React form's visible text is not what submits.** Verify after forcing a re-render, or
   write through React's own value setter.
3. **Check the live system, not the project note.** CLAUDE.md said Stripe was in sandbox; the
   account was live. That nearly went to a financial institution as a false statement.
