until proven otherwise (the session-140 rule).

## 🔴 The mirror blind spot — found by injecting the fault, and it was real

**20 faults injected against THIS batch's own 23 rows.** First run: **19/20**, control
clean before and after. The one miss was **`malformed sourceURL`**.

Per the standing rule I **read `validate-tours.swift` before calling it a blind spot** —
because sessions 142 and 143 each shipped a "blind spot" that was a rule they had
invented. This one is genuine: **lines 556–562 error on a link pin with an invalid
`sourceURL` or an empty `sourceAuthor`**, and the mirror checked neither. It also errors
when a **non-link** tour carries either field, which the mirror also missed.

Closed: all three rules added and **pinned in the mirror's own selftest, which goes
24/24 → 27/27 with a clean control**. Re-run: **20/20 caught.**

⚠️ **The harness counts errors AND warnings** — "no Place type" and "no Theme" are
*warnings*, and counting only errors reports false misses (the session-141 bug).

⚠️ **`load_vocab()` returns `(facets dict, flat tag set)` and `check()` takes
`(cat, facets, vocab, dom)`.** Unpacking it the other way round fails with
`'set' object has no attribute 'get'` — one wrong guess, one wasted run. It is written
down here so the next session does not pay for it again.
