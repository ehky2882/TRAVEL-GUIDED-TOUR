## Decisions taken (both flagged in the PR)

1. **Geofence radius — went with the catalog, not the READMEs.** Every Madrid
   staging README says "geofence ~40 m" for singles. Every *other* city in the
   catalog ships singles at **30 m** (the documented city-launch default). Madrid
   singles therefore ship at **30 m**, walk stops at **40 m** with a `manual` intro
   — identical to AMS / LAX / YYZ. Trivial to flip if the owner prefers 40.
2. **The tracker's Madrid count was one over.** It recorded *31 singles / 56 MP3s*;
   the actual staged set is **30 / 55**. Corrected in `AUDIO-PENDING-SURVEY.md`.

## Reusable machinery

Three throwaway files under `/tmp/madrid-work/` drove the whole assembly and are
worth recreating for Montreal / Rome / Berlin:

- **`spec.py`** — the editorial table: per-tour title, coord, category, gallery
  count, tags, shortDescription, longDescription; plus the walk stop lists. This is
  where all the actual authoring lives.
- **`assemble.py`** — mechanical and **idempotent** (it strips any existing entries
  for the maker before appending, so re-running never duplicates). Handles the
  `[beat]` strip, the ALL-CAPS title-header strip, caption extraction, uuid5 ids,
  duration lookup and the catalog merge.
- **`durations.json`** — slug → seconds, from `afinfo`.

**Caption rule that took two passes to get right.** `caption` is the script's
opening sentence — but many Madrid scripts open with a bare instruction
("Stand still for a second.", "This street looks grand and old.") that means
nothing standing alone. Final rule: take the first sentence; if it is under
40 characters, append the second (unless that would blow past 320). Result:
shortest caption 42 chars, longest 296, no fragments, no double spaces.

**Two tooling notes for future local sessions on this Mac:**
- Python's `urllib` fails SSL verification here (`CERTIFICATE_VERIFY_FAILED`, no
  local issuer certificate). Use `curl` for URL checks.
- `xargs -P` on a 173-line URL list died with *"command line cannot be assembled,
  too long"* and — worse — still exited 0, so it looked like a clean pass. A plain
  `while read` loop is the safe form. Do not trust a zero-failure count from an
  `xargs` invocation that printed an error.
