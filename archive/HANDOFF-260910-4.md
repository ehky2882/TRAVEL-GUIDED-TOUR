## The documents (PRs #756, #757, #759, #764, #765, #766)

The owner reported three symptoms — plan limits gone in a few turns, `prompt too long` on short
prompts, sessions no longer auto-compacting — and asked whether the catalogue had grown too big.
**It had not.** `CLAUDE.md` was **1,505,116 bytes — ~418,000 tokens on every request of every
session**, 97.7% of it dated `## Current State` blocks. It exceeded a context window on its own,
which is why short prompts were rejected; and compaction could never reclaim it **by design**,
since compaction summarises the conversation while the file is re-injected fresh afterwards.

Then the same pattern turned up in three more files. Each is a heading promising the present tense
sitting on a log every session appends to and nobody prunes.

| File | The section | Before → after |
|---|---|---|
| `CLAUDE.md` | § Current State (97.7%) | 1.5 MB → **47 KB** |
| `ROADMAP.md` | § "Where we are right now" (86%) | 428 KB → **98 KB** |
| `archive/README.md` | the index rows themselves (94%) | 475 KB → **32 KB** |

All history moved verbatim to `archive/{CURRENT-STATE,ROADMAP-STATUS,INDEX-DETAIL,STATUS}-HISTORY.md`.
**Zero lines lost on any of the four**, verified against `git show <ref>:<file>` rather than the
scripts' own memory.

## ⚠️ Two mechanics worth inheriting

**gh-pages cannot be cloned from a web session** — `fatal: fetch-pack: invalid index-pack output`
on a branch carrying every audio file — and **the REST contents API is blocked for writes through
this proxy**. Both dead ends. What works: a **blobless partial fetch** plus plumbing —

```bash
git fetch --no-tags --depth=1 --filter=blob:none origin gh-pages
GIT_INDEX_FILE=/tmp/idx git read-tree origin/gh-pages
GIT_INDEX_FILE=/tmp/idx git update-index --add --cacheinfo 100644,$(git hash-object -w f.webp),images/f.webp
# write-tree → commit-tree -p origin/gh-pages → git push origin <commit>:refs/heads/gh-pages
```

— which adds a file without downloading a single blob.

**A pasted image never reaches the filesystem.** Three pastes, three filesystem sweeps, nothing.
Ask for a **URL**, not another paste.

## 🔴 The thread through the whole session

**Four separate times something looked like a pass without having run.** A stale output file; a
parser silently dropping a third bullet format; an id check that passed every unit test and broke
idempotence only against the real catalogue; and a CI watcher that **exited cleanly having never
checked the last job** — its loop ran out, returned 0, and would have merged mid-test.

The rule that covers the last one, now in `docs/lessons.md`: **a waiting loop must distinguish
"the thing finished" from "I stopped waiting."** Its replacement prints
`TIMED OUT — DO NOT read this as a pass` and pins to an exact commit SHA.
