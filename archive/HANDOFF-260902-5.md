## 🔴 The first verification pass was worthless and nearly shipped as a verdict

Nominatim rate-limited it: **52 of 57 came back HTTP 429**. The check tested only whether a country
field was empty, so it reported all 52 as **"region outliers"** — a list I was one step from acting
on. **An errored record is now excluded from the result file entirely**, so a request that never
completed cannot produce a verdict, and the re-run has retry-with-backoff (it still needed a second
pass for 4 stragglers).

**Durable: a check that cannot reach the network must not be able to return an answer.** This is the
`check-image-duplicates.py` founding lesson in a new place.
