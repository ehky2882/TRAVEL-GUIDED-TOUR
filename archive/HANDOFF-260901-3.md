## The Plus Code decoder

`pip install openlocationcode` still cannot build a wheel here (third session running), so it was
hand-written again: `/tmp/plus.py`, pairs only.

🔴 **It REFUSES codes with grid digits (>10) rather than guessing.** The grid's row direction —
whether row 0 is the north or south edge of the cell — cannot be settled from any vector I could
verify in this container, and **no code in this batch uses one** (all twelve are 10-digit or their
short forms). Raising beats a silent 1-in-5 chance of a cell-height error. If a future batch brings
an 11-digit code, settle the direction against a *published* anchor before implementing it.

**Self-test: 18 checks + 2000 round-trips, and it failed three of them first time.** Two failures
were my own hand-derivations and one was a real bug — the documented split:

- ⚠️ **Two wrong expectations.** I mis-split `87G8M2J6+HJ` into pairs, reading the latitude digits
  as `8,G,2,6,H` when the pairs are `(8,7)(G,8)(M,2)(J,6)(H,J)` and the latitude digits are
  `8,G,M,J,H`. The decoder was right. **This is the documented pattern — the memory of a vector is
  the usual culprit** — so every expectation is now derived from the pair table `[20, 1, 0.05,
  0.0025, 0.000125]` in the test itself.
- 🔴 **One real bug: `encode` must FLOOR, not round.** Rounding tipped a point sitting exactly on a
  cell boundary into the next cell — the Eiffel Tower centre `2.2944375` scales to `1458355.5`
  units, and rounding gave `8FW4V75V+8R` where the answer is `+8Q`. It also failed **1483 of 2000**
  round-trips. Now floored exactly via `Fraction`, which is 2000/2000.

Anchors it is checked against: the **Eiffel Tower** `8FW4V75V+8Q` → 48.8583125, 2.2944375 (the
value CLAUDE.md records as verified, and my hand-derivation off the pair table reproduces it), and
**`7FG49Q00+`** → 20.375, 2.775, the specification's own six-digit example. Plus the −74° NYC pair
boundary: a Manhattan point encodes `87G8`, a point at −74.006 encodes `87G7`, and three of this
batch's short codes correctly recover across it.
