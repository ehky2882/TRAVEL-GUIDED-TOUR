## 5. Windsor Castle gets a real photograph of Windsor Castle

🔴 **The problem was structural, not laziness.** Windsor's place hero was borrowed because **none of
its six members carries a picture of the castle at all** — an armour, three portraits, a drawing room
and a postbox. It shipped with the Crimson Drawing Room as the least-bad option and has been flagged
since [#679](https://github.com/ehky2882/TRAVEL-GUIDED-TOUR/pull/679) as the weakest of the borrowed
heroes.

**Now sourced: the Round Tower**, on the motte William the Conqueror raised in the 1070s — which is
exactly what the place's own description names. No people, no cars, no burned-in text.

- **CC0** from Wikimedia Commons (`Windsor Castle Round Tower.JPG`, 4000×3000, 2008), confirmed
  **twice**: the Openverse query was filtered `license=cc0,pdm`, and the Commons API's own
  `extmetadata` reports CC0. **CC0 carries no attribution obligation, so no CREDITS row is owed** —
  which is the entire reason the catalogue's policy is PD-only.
- **Natively 4:3**, so the 1200×900 hero is a clean downscale with **nothing cropped and no
  upscaling**. Asserted in the build (`abs(w/h - 4/3) < 0.01` and `w>=1200`), not eyeballed.
- ⚠️ **It is a photograph, not a print — the documented hazard on a famous old landmark under a
  PD-only policy.** The filter rejected exactly that: Rijksmuseum `RP-F` plates, a 17th-century
  Cleveland Museum painting, Yale Center for British Art drawings, plus two Windsor Castle **pubs**
  and a set of Garter crests in an Essex church.
- ⚠️ **The rawpixel candidates were rejected on a mechanical ground too** — their URLs deliver
  `editor_1024`, so an advertised 6358×7906 would in fact have been a 1024px upscale.
- **Three other CC0 frames from the same photographer's 2011 visit were opened and rejected**: two are
  close details of the Round Tower's parapet (one with an aircraft on the Heathrow approach), and the
  third is **St George's Chapel** — genuinely one of the great sights here, and named in the
  description — but **parked cars fill its foreground and a person's head sits bottom-right.**

**Uploaded to gh-pages first** (`0b955e8d`), tree diff **exactly one addition, nothing outside
`images/`**, under a filename verified free against all **6,380** existing image paths, with the
remote head **re-read in the same command as the push**.

### ⚠️ Wikimedia rate-limiting, and how to get round it

`upload.wikimedia.org` returned **HTTP 429** on every direct file fetch, and the **Commons API itself**
rate-limited a five-title batch request while single-title requests returned 200 — so this IP is
throttled globally, not per-endpoint. Three things that worked:

1. **An error page gets written to the file and looks like a download.** All five first attempts
   produced 2,256-byte "Wikimedia Error" HTML with a 200-shaped filename. **The size check caught it**
   — the `check-image-duplicates.py` founding lesson, live again. Always check the bytes.
2. **Do not hand-build thumbnail paths.** A constructed `/thumb/<a>/<ab>/<file>/2560px-<file>` URL
   returned **400**. The **MediaWiki API's `imageinfo` with `iiurlwidth`** hands back a correct
   `thumburl`, and the licence and capture date alongside it.
3. **Pace it at ~8 s between requests with a retry-with-backoff**, and run it in the background while
   doing other work. Four of five files landed; the fifth (`Windsor Castle 2011 09`) still API-failed
   and was simply not needed.
