## Process notes

- **A batch this size needs a cached single-pass grab**, not the tool's own retry loop: resolve
  short links once to disk, fetch oEmbed once to disk, then work offline. 106 links resolved in
  ~4 minutes and 106 payloads in ~5.
- **`make_one` is the right entry point for a per-row batch.** `--batch` ignores `--slug` past
  the first row, so it cannot carry per-row titles, slugs, categories and tags.
- **A running driver holds its imported table in memory** — editing the editorial file mid-run
  does nothing, so a retitle after generation has started needs an explicit regenerate.
- **`sleep` in a foreground shell is blocked**; use `until <check>; do sleep N; done` or a
  background command.
