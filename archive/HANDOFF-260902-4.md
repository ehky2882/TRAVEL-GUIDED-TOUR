## The finding

Round 3 swept the deferred venues with five query strategies and recovered almost nothing, and that
was written up as the definitive answer: *small independent HK food shops are largely absent from
OSM.* **That is true of most of them and was the wrong conclusion for fifteen**, because the failure
was never in the query — it was in **the venue string the caption gave us**:

| Defect | Examples |
|---|---|
| a compound name never split | `Chi Lin Nunnery & Nan Lian Gardens` |
| an OSM spelling that differs | `CTMA Mall` → **CTMA Centre** · `Sino Center` → **Sino Centre** · `City Gate Outlet` → **Citygate Outlets** · `Olympic City` → **Olympian City** |
| a shop whose ENCLOSING building is named in the caption **and is mapped** | D2 Place · Kwai Chung Plaza · Fashion Walk · Monster Building · Harbour City · Regent Hong Kong · Stanley Market |

**Durable: when a geocoding round comes back empty, re-read the venue strings before concluding the
subject is unmapped.** Five strategies over a wrong string is still a wrong string.

## 🎉 The best of them was not an enclosing-feature pin at all

`Chi Ming Mahjong, 60 Fa Yuen Street, Mong Kok` — searching **the house number the caption itself
carries** returns OSM's node for **the shop**, `Chi Ming Majong Shop`, **forward and reverse**. The
address was inside the venue string, unparsed, from the first pass.

## 🔴 Two mistakes of mine, both caught by a check rather than by reading

1. **Nine of the fifteen shortcodes in the geocoding pass were typed from memory and do not exist in
   this batch.** Six were right only because they had been copied from a tool result. Caught by
   re-deriving every code from `geo.json` by venue name before building. **The build script now looks
   each code up and asserts it**, so a hand-typed code cannot reach a pin.
2. **A sixteenth entry was already live.** `Chi Lin Vegetarian` shipped in #708; its hero already
   existed on gh-pages, which is what the **collision check** flagged. Root cause: the plan was built
   from a keyword query over all 116 rows rather than from the unshipped list. The shipped set is now
   extracted with a regex over `sourceURL` and asserted per row.

## Round 5 — swept the rest, and mostly confirmed the deferral

Fifteen further candidates that plausibly *are* named in OSM. Seven returned something, and **six of
those returned a SUBURB, an MTR STATION or a ROAD** rather than the venue — the same district-level
fallback that deferred them originally (`San Tin` the suburb, `Long Ping` the MTR station, `Apliu
Street` the road, `San Po Kong` the suburb, `Kam Tin` the suburb). **They stay deferred.**

  empty** — this is one of the two posts with no `📍`, identified from the picture during the hero

  at Ocean Park Hong Kong"*, over the Grand Aquarium tank), which also settles the tagging: it takes
  **Two Oceans Aquarium's exact set**, `natureAndParks` + `[Venue, Waterfront, Maritime]`.

  Granville Road, and the caption says only *"Tsim Sha Tsui"*. Picking one would be a guess. Same
  reason Komeda, Chagee and Lin Heung were deferred in the first pass.
