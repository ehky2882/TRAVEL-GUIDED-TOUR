# Udaipur batch 1: scripts staged, no audio yet

**24 single-stop tours** from Studio Saar's Architecture Hunter city guide (https://architecturehunter.com/guide/udaipur-india/), staged 2026-10-12. Each tour has a clean `.txt`, a `.md` (with its sources), and a `_TTS.txt` (respelled, no `[beat]`, no hyphens, years spelled out). The narration starts after the `---` in each clean `.txt`.

Udaipur has no Atlas tours yet, and no studio code is assigned. **Owner's call:** whether this is a new Atlas Studio (e.g. UDR) and which tours to record.

## Owed before wire-in / flags for the owner
1. **04 Upri Manzil vs Upré.** The guide's text says "Upré" but its map pin is *Upri Manzil Rooftop Restaurant* at Hanuman Ghat. A different, upmarket rooftop called *Upré by 1559 AD* exists at Hotel Lake Pichola. The script follows the pin (Upri Manzil). Confirm.
2. **09 Tapri Niwas and 16 Ladu share one coordinate** (the guide puts Ladu at Tapri Niwas). Kept as two tours, as asked. The Ladu facts come from its Jaipur original; that it operates at the Udaipur site rests on the guide alone.
3. **05 Lily Court and 14 Bougainvillaea Art Gallery are ~80 m apart** on the same highway site. Each script points to the other.
4. **23 Karni Mata:** the guide's pin is in Jawahar Nagar, south-east of the hill, presumably the start of the back trail. The temple itself is on Machla Magra. Check the pin before wire-in.
5. **06 Ninkasi:** the design details (Studio Rust, Sumerian theme, folk-art paintings, jharokha arches) come from the architects' write-up on re-thinkingthefuture.com, which returned 403 to a direct fetch. They were read via its search excerpt only.
6. **15 Ganesh Emporium:** the seventeenth-century date is the guide's alone. The script attributes it to the guide.
7. **TTS respellings to listen for:** Udaipur → Oodaypoor, Pichola → Pichohla, Mewar → Mayvaar, haveli → havaylee, Aosa → Ah osa (actual pronunciation unknown), Syah → Seeyah.
