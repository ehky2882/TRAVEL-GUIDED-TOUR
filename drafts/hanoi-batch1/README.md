# Hanoi batch 1 — Atlas Studio HAN (28 singles) — LIVE 2026-10-14

Source: contributor drop (Dropbox), SovMod/Auckland format: one `output <Name> <lat>, <lon>` folder per site,
each with `hanoi_NN_<slug>.txt` (script, header above `---`), `_TTS.txt`, an MP3 and 1–7 webp photos at 1200×900.
`scripts/` holds both texts as delivered; `coordinates.tsv` is num · slug · lat · lon · radius · category · note;
`tools/wire_hanoi.py` is the assembler (run once — it refuses to add the maker twice).

Every slug carries a **`han-` prefix**: an abandoned earlier attempt left 35 unreferenced Hanoi photos on gh-pages
under the bare names, some with different bytes, and live bytes are never overwritten. Audio is at
`audio/han-<slug>.mp3`, images at `images/han-<slug>_hero.webp`, `_2.webp`, … (the drop's own `*_hero.webp`, where
present, leads). Captions are each script's "Vantage" line. Full account: `archive/HANDOFF-261014-hanoi.md`.
